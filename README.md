# homebrew-tap

Personal Homebrew tap by [@cytsai1008](https://github.com/cytsai1008).

## Install

```sh
brew tap cytsai1008/tap
brew trust cytsai1008/tap
```

## Formulae

| Formula | Description |
|---------|-------------|
| `brew-cnf` | Fast drop-in replacement for `Fast drop-in replacement for brew command-not-found` |

## Casks

| Cask | Description |
|------|-------------|
| `mibuds-for-mac` | MiBuds for Mac: menu bar app for Xiaomi and Redmi earbuds battery and noise control ([MiBudsForMac](https://github.com/cytsai1008/MiBudsForMac)) |

## Usage

```sh
brew install cytsai/tap/<formula>
brew install --cask cytsai1008/tap/<cask>
```
