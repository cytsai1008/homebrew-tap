# homebrew-tap

Personal Homebrew tap by [@cytsai](https://github.com/cytsai1008).

## Install

```sh
brew tap cytsai1008/tap
brew trust cytsai1008/tap
```

## Formulae

| Formula | Description |
|---------|-------------|
| `brew-cnf` | Fast drop-in replacement for `brew which-formula --explain` |

## Usage

```sh
brew install cytsai/tap/<formula>
```
